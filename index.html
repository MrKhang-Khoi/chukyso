Cách 2 KÝ BẰNG USB TOKEN PHẦN CỨNG CẮM VÀO MÁY TÍNH KHÁC

👉 Khi mang USB Token cắm vào máy tính khác, máy tính đó cần có công cụ EduSign Agent 2.0 chạy ở khay hệ thống Windows để trình duyệt kết nối với USB Token.

Các bước cài đặt chuẩn Windows (Có hộp thoại hướng dẫn & tạo Shortcut Icon):
  1. Bấm nút "Tải EduSign Agent 2.0 (.ZIP - Khuyên dùng)" để tải từ máy chủ GitHub siêu tốc (không lo bị Windows chặn tệp).
  2. Mở file ZIP vừa tải, nhấp đúp chạy EduSign_Agent.exe.
  3. Hộp thoại cài đặt chuẩn Windows sẽ xuất hiện: Thầy/Cô chỉ cần nhấn [Cài đặt ngay], hệ thống sẽ tự động cài đặt vào máy tính, tự tạo biểu tượng Desktop có Icon nhận diện, thêm vào Menu Start và tự động khởi động cùng Windows.
  4. Cắm USB Token Ban Cơ yếu vào cổng USB máy tính và thực hiện ký số trên web bình thường!

Chỉnh Sửa Thông Tin Chữ Ký Số

Học bạ số Bộ GD&ĐT • Quản lý thiết bị & đối soát USB Token Ban Giám hiệu

Phương thức ký số chứng thực công vụ Ban Giám hiệu theo chuẩn Thông tư Bộ GD&ĐT.

Số Serial duy nhất trong chip bảo mật phần cứng USB Token để đối soát khi phê duyệt.
Quy định đối soát chữ ký số Ban Giám hiệu: Khi thực hiện "Phê duyệt & Đóng dấu số", EduSign Agent sẽ kiểm tra trực tiếp số Serial của USB Token cắm ở máy tính. Nếu số Serial không trùng khớp với số Serial đăng ký ở đây, lệnh ký số sẽ bị chặn ngay lập tức để phòng chống việc dùng sai thiết bị hoặc ký thay trái phép.

Hạ Tầng Cloud Realtime (Mô Hình 3)

Google Cloud Firestore & Firebase Hosting CDN

Trạng thái kết nối: Local Server Mode

Hệ thống đang hoạt động qua máy chủ REST API. Để bật chế độ Realtime Sync tức thì (không cần bấm F5) và giúp trang web mở ngay trong 0.3s (không bị ngủ đông Render), Thầy/Cô cấu hình thông tin Firebase miễn phí bên dưới.

3 Bước kích hoạt Firebase (Miễn phí 100% trọn đời):
Bước 1: Truy cập Firebase Console, đăng nhập Google và bấm [Add Project] (ví dụ: edusign-school).
Bước 2: Vào Build -> Firestore Database -> bấm [Create database] (chọn máy chủ Singapore asia-southeast1).
Bước 3: Vào Project Settings -> Web App </>, sao chép firebaseConfig và dán vào file: public/firebase-config.js rồi đổi enabled: true.
Lợi ích khi kích hoạt:
• Không bao giờ bị ngủ đông 50s như Render Free. Tốc độ mở web < 0.3s.
• BGH cắm USB ký duyệt, màn hình Giáo viên tự đổi màu Xanh Lá ngay lập tức.
• Tải lên và ký số phân loại tự động vào Google Drive của trường.
