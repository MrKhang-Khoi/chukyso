HƯỚNG DẪN CÀI ĐẶT & KÝ SỐ TRÊN MÁY TÍNH KHÁC

Giải đáp chi tiết cách sử dụng và cài đặt phần mềm ký số EduSign VGCA

1. Phân tích 3 thành phần trên màn hình máy tính (Hình 3):
EduSign Agent

Phím tắt (Shortcut): Biểu tượng lối tắt ngoài Desktop giúp mở nhanh ứng dụng chạy ngầm ở khay hệ thống Windows.

Cai_Dat_Ed... (.bat)

Bộ cài đặt một chạm: File kịch bản tự động sao chép chương trình, tạo biểu tượng Desktop và cho phép tự khởi động cùng Windows.

EduSign_A... (.exe)

Chương trình thực thi chính: Ứng dụng cầu nối (Local Signer Bridge) nhận diện và kết nối trực tiếp với USB Token Ban Cơ yếu.

2. Để chạy trên máy tính khác thì cần cài những phần nào?
Cách 1 - Khuyên dùng KÝ SỐ QUA ĐIỆN THOẠI (SmartCA / VGCA Mobile)
Không cần cài đặt

👉 Thầy/cô KHÔNG CẦN CÀI ĐẶT BẤT KỲ PHẦN MỀM NÀO lên máy tính!
Chỉ cần mở trình duyệt web trên bất kỳ máy tính hay điện thoại nào, đăng nhập hệ thống, nhấn [Ký duyệt] và mở ứng dụng VGCA / SmartCA trên điện thoại nhấn [Đồng ý] là ký thành công 100%!

Cách 2 KÝ BẰNG USB TOKEN PHẦN CỨNG CẮM VÀO MÁY TÍNH KHÁC

👉 Khi mang USB Token cắm vào máy tính khác, máy tính đó cần có công cụ EduSign Agent chạy ngầm để trình duyệt kết nối được với USB Token.

Các bước thực hiện trên máy tính mới:
  1. Bấm nút "Tải Cài đặt (.bat)" hoặc "Tải EduSign Agent (.exe)" ở bên dưới.
  2. Nhấp đúp chuột vào file vừa tải về để cài đặt tự động (file .bat sẽ tự thiết lập và tạo biểu tượng ngoài Desktop như Hình 3).
  3. Cắm USB Token Ban Cơ yếu vào cổng USB của máy tính và tiến hành ký duyệt trên web bình thường.
